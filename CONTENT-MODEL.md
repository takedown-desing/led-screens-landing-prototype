# Модель управляемого контента

Требование брифа: «Контент на лендинге должен быть управляемым». Ниже сущности и поля для админки на этапе разработки. На лендинге каждое управляемое место помечено атрибутом `data-cms="…"`, кнопка «Управляемые поля» в верхней панели подсвечивает их.

Платформа не выбрана. Модель подходит для любой headless CMS (Strapi, Directus, Payload), для WordPress с ACF или для Tilda / Битрикс с инфоблоками. Принцип: один лендинг, тексты и списки хранятся отдельно от вёрстки, редактор меняет данные без правки кода.

## Одиночные сущности

### Настройки сайта

| Поле | Тип | Где выводится |
|---|---|---|
| Название компании (короткое) | строка | шапка, логотип |
| Название компании (полное) | строка | «О компании», подвал |
| Логотип | изображение (svg/png) | шапка |
| Слоган под логотипом | строка | шапка |
| Телефон | строка | шапка, контакты, подвал, липкая панель, мобильное меню, призыв |
| Email | строка | контакты, подвал, мобильное меню |
| Контактное лицо: имя, роль, фото | строка, строка, изображение | шапка (подпись к телефону), контакты |
| Режим работы | строка | шапка, контакты |
| Адрес офиса и склада | строка | контакты, карта |
| Координаты для карты | строка | контакты |
| Ссылки мессенджеров: WhatsApp, Telegram, MAX | url, url, url | контакты, мобильное меню, подвал |
| Реквизиты | текст | подвал |
| Ссылка на политику обработки ПД | url | все формы, подвал |
| Счётчики аналитики (Метрика, GA4) | текст | head |
| Title и description страницы | строка, строка | head |

### Первый экран

| Поле | Тип |
|---|---|
| Бейдж региона | строка |
| Заголовок H1 | строка |
| Подзаголовок | текст |
| Фон: видео (mp4) и постер, или фото | файл, изображение |
| Три факта: заголовок, подпись | список из 3 пар |
| Тексты кнопок: основная, вторичная, подпись | строка ×3 |
| Заголовок и подпись формы | строка, строка |

### Настройки калькулятора

| Поле | Тип |
|---|---|
| Доля монтажа и конструкции от стоимости экрана | число, % (по умолчанию 15) |
| Что не входит в ориентир | текст |
| Подпись под результатом | текст |
| Заголовок и подзаголовок блока | строка, текст |

Ставки за м² и рекомендуемый шаг берутся из сущности «Тип экрана».

### О компании

| Поле | Тип |
|---|---|
| Заголовок | строка |
| Абзацы | текст ×2 |
| Фото | изображение |
| Документы и факты | список: иконка, текст |

### Призыв (CTA-полоса)

| Поле | Тип |
|---|---|
| Заголовок, текст, текст кнопки | строка, текст, строка |

### Заголовки разделов

Для каждого блока: надзаголовок, заголовок, подзаголовок, флаг «показывать блок». Блоки: типы экранов, объекты, что входит, как работаем, стоимость, подбор, о компании, отзывы, вопросы, контакты.

## Списки

### Тип экрана

| Поле | Тип | Примечание |
|---|---|---|
| Название | строка | заголовок карточки |
| Описание | текст | 2–3 предложения |
| Фото | изображение | 16:10 |
| Подпись к фото | строка | «Фото клиента», «Кадр из видео» |
| Характеристики | список до 4: название, значение | |
| Ставка за м², «от» | число | калькулятор и таблица ставок |
| Рекомендуемый шаг пикселя | строка | вывод в калькуляторе |
| Ключ фильтра | строка | связь с кейсами: outdoor, transparent, indoor, bridge, flex |
| Показывать в селектах форм | флаг | |
| Порядок, показывать/скрыть | число, флаг | |

### Кейс (объект)

| Поле | Тип |
|---|---|
| Название | строка |
| Описание | текст |
| Тип экрана | ссылка на «Тип экрана», можно несколько |
| Видео (mp4, до 10 МБ) | файл |
| Превью (постер) | изображение |
| Параметры | список до 3: название, значение (площадь, шаг, город) |
| Порядок, показывать/скрыть | число, флаг |

### Число доверия

Значение, подпись, порядок. Ровно четыре показываются.

### Пункт состава услуги

Иконка (из набора), название, описание, порядок.

### Этап работы

Номер, название, описание, срок, порядок.

### Строка таблицы подбора

Шаг пикселя, минимальное расстояние, применение, тип экрана, яркость, порядок.

### Отзыв

Имя или компания, объект (что и сколько м²), текст, оценка 1–5, порядок, показывать/скрыть. Если ни одного видимого отзыва, блок не выводится.

### Вопрос и ответ

Вопрос, ответ (форматированный текст), порядок, открыт по умолчанию.

## Формы и заявки

### Настройки форм

| Поле | Тип |
|---|---|
| Подписи и плейсхолдеры полей | строки |
| Список типов экрана в селекте | из «Тип экрана» с флагом «показывать в селектах» плюс пункт «Не знаю» |
| Текст согласия | текст |
| Текст подтверждения после отправки | строка |
| Адреса для писем с заявками | список email (по брифу imenshov@addu.ru) |
| Уведомление в мессенджер | токен и чат Telegram |
| Защита от спама | ключи капчи |

### Журнал заявок

Дата, источник (какая форма и кнопка), тип экрана, размеры, имя, телефон, email, комментарий, вложения, UTM-метки, статус обработки.

## Что не управляется

Порядок блоков и вёрстка. Если клиенту нужно менять порядок блоков, это отдельное требование к платформе (конструктор секций), обсуждается на этапе выбора CMS.
