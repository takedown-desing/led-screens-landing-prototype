# Модель контента

Весь контент лендинга хранится в `content/landing.json`. Страница `landing.html` собирается из него скриптом `assets/render.js`, админка `admin/` правит этот файл. Разделы и поля админки описаны в `admin/schema.js`: чтобы добавить поле, достаточно дописать его туда и вывести в `render.js`.

Во всех текстовых полях работают два правила:

* `[[текст]]` выводится с оранжевой подсветкой как условное значение;
* пустая строка в многострочных полях «О компании» и «Ответ» начинает новый абзац.

## Разделы файла

| Ключ | Раздел админки | Поля | Где на сайте |
|---|---|---|---|
| `meta` | Контакты и общие данные | title, description | вкладка браузера, выдача |
| `settings` | Контакты и общие данные | значок и название, полное название, контактное лицо, телефон, режим, email, адрес, ссылки WhatsApp / Telegram / MAX, кнопка шапки, текст после отправки формы, ссылка на политику | шапка, мобильное меню, контакты, подвал, липкая панель, формы |
| `blocks` | Блоки: порядок и показ | список блоков: id, показывать, пункт меню | порядок секций, меню шапки и подвала |
| `hero` | Первый экран | регион, H1, подзаголовок, фоновое видео, картинка фона, до 3 фактов, две кнопки, подпись, заголовок и кнопка формы | первый экран |
| `trust` | Цифры доверия | до 4 пар «число, подпись» | полоса под первым экраном |
| `screens` | Типы экранов | заголовки блока, кнопка «Помочь с выбором», карточки: название, короткое название, описание, фото, подпись к фото, характеристики, ставка за м², шаг пикселя, фильтр для «Примеров», показывать | карточки, списки типов во всех формах, калькулятор |
| `cases` | Объекты (видео) | заголовки, название фильтра «все», фильтры, объекты: тип, название, описание, видео, превью, фильтры, параметры, показывать | объекты с фильтром |
| `included` | Что входит | заголовки, пункты: иконка, заголовок, текст | «Что входит» |
| `process` | Как работаем | заголовки, этапы: название, описание, срок | этапы, номера проставляются сами |
| `calc` | Стоимость и калькулятор | заголовки, тип и размеры по умолчанию, доля монтажа, подпись галочки, «ставки условные», что не входит, кнопка | калькулятор; ставки берутся из `screens` |
| `specs` | Таблица подбора | заголовки, строки: шаг, расстояние, применение, тип, яркость | таблица подбора |
| `about` | О компании | надзаголовок, заголовок, текст, фото, документы: иконка, текст | «О компании» |
| `reviews` | Отзывы | заголовки, отзывы: имя, объект, текст, оценка, показывать | отзывы; блок скрывается, если видимых нет |
| `cta` | Призыв | заголовок, текст, кнопка, показывать телефон | полоса-призыв |
| `faq` | Вопросы и ответы | заголовки, вопросы: вопрос, ответ, раскрыт по умолчанию | вопросы |
| `contacts` | Контакты и форма | заголовки, заголовок, подпись и кнопка формы, заглушка карты | контакты; телефон и адрес из `settings` |
| `footer` | Подвал | описание, реквизиты, примечание | подвал |

## Файлы

Фото и видео хранятся в репозитории. Исходные материалы из брифа лежат в `assets/img/` и `assets/video/`, всё загруженное через админку попадает в `assets/uploads/`. Ограничение на файл 50 МБ, для видео рекомендуется до 10 МБ.

## Что не входит в прототип

* Отправка заявок и журнал заявок: нужен сервер, делается на этапе разработки.
* Вход в админку по логину и паролю: сейчас вход по токену GitHub.
* Пометки прототипа на блоках (синие, зелёные, оранжевые ярлыки): это служебная разметка, в админке не редактируется и в боевой версии убирается.
