# Вариант 4 · Сцена

Вариант по макету дизайнера с led.addu.fun и отзыву Макса (07.10.2026). Суть отзыва: варианты 1–3 выглядят «целиком сгенерированными ИИ» (лишние графические элементы, технические тексты с точкой после каждой фразы, тяжело читать). Пример Макса: первый экран — LED-экран, который при прокрутке «устанавливается» на стену и так показывает, чем занимается компания; дальше свобода.

Открывать через веб-сервер из папки `prototype/`: `python3 -m http.server 8796` → `http://localhost:8796/design/v4/`.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Каркас: шрифт Wix Madefor Display (Google Fonts), Three.js r128 с cdnjs, стили, скрипты, плашка варианта |
| `scene.js` | Первый экран-сцена: 3D-зал, прокрутка, отражение, стыки кабинетов |
| `render.js` | Сборка страницы из `../../content/landing.json` |
| `app.js` | Интерактив: модалка, меню, карусель, лайтбокс, калькулятор, FAQ, автовидео (из варианта 3), плюс цифры-барабаны и выбор типа экрана |
| `styles.css` | Стили. Цвета в CSS-переменных, акцент `--blue: #3054ff` |

## Что взято из макета дизайнера

* Первый экран: видео на весь экран, при прокрутке экран уменьшается и встаёт на стену тёмного зала (кессонный потолок, круглые светильники, пол с плиткой). Свет в зале берёт цвет из текущего кадра видео. Текст и кнопки остаются на экране и уменьшаются вместе с ним.
* Шрифт Wix Madefor Display, крупные заголовки 500 с плотным трекингом, синий `#3054ff`, голубые цифры `#4b8dff`.
* Шапка: тёмная полупрозрачная с размытием, телефон с зелёной точкой и подписью, почта, синяя кнопка-пилюля.
* Кнопки-пилюли: текст прокручивается вверх при наведении, стрелка в круге поворачивается.
* Цифры доверия «барабанами» на тёмном фоне с размытым видео, переход градиентом в светлую «бумагу» `#f3f1ea`.
* Редакционная вёрстка остальных секций по базовым стилям макета: заголовок слева и подзаголовок справа, списки на тонких линиях, FAQ с плюсом, поля форм с нижней линией.

## Что добавлено

* Отражение видео в полу зала и стыки кабинетов 500×500, которые проступают, пока экран «едет» на стену, и гаснут после установки (как сборка и калибровка). После установки под экраном появляются три факта из `hero.facts`.
* Человек, проходящий мимо экрана в макете, не перенесён: это сканированная 3D-модель Renderpeople с сервера дизайнера (`nathan-visitor.glb`), под лицензией Renderpeople. Без согласования её не копировали; если дизайнер передаст файл, сцену можно дополнить.
* Типы экранов списком строк, без карточек: слева названия с шагом пикселя, справа видео, описание, цена за м², характеристики и кнопка расчёта. На компьютере переключается наведением, на телефоне раскрывается под строкой.
* Тёмные блоки (объекты и калькулятор) скруглены и отбиты от краёв, как экраны на светлой странице.
* Иконок-плиток, эмодзи, градиентных рамок и бейджей нет.

## Тексты

* Короткий заголовок первого экрана из макета Макса «LED-экраны для вашего бизнеса» вынесен в новое поле `hero.titleShort` (админка, «Первый экран» → «Короткий заголовок на видео»). Пустое поле — выводится `hero.h1`. Другие варианты это поле не читают.
* Подписи из одной фразы выводятся без точки в конце (функция `soft` в `render.js`), абзацы из нескольких предложений остаются как в JSON. Сами тексты в JSON не менялись: переписывание копирайта под замечание Макса — отдельная задача для всех вариантов.

## Откуда берётся контент

Всё из `content/landing.json`, того же файла, что правит админка. Порядок и видимость блоков из `blocks`, меню из `blocks[].menu`. `[[текст]]` выводится обычным текстом. Медиа-пути получают префикс `../../`. Тон секций: светлые чередуются «бумага» / белый, объекты и калькулятор тёмные, CTA синяя.

Тексты, заданные в коде (полей в модели нет): «Хочу такой же», «Хотите такой же экран?», «Пришлите фото места, посчитаем за день», «Нажмите на объект, чтобы посмотреть видео со звуком», «Рассчитать этот экран», «Смотреть объекты», «Не знаете, какой нужен?…», подписи калькулятора и таблицы шага пикселя, «Не нашли ответ?», подписи полей форм. Видео-полоса в «Что входит» берёт ролик `case-pedestrian-bridge-night` (константа `INCLUDED_MEDIA` в `render.js`).

## Известные ограничения

* Без WebGL или при включённом «уменьшить движение» первый экран статичный: видео на весь экран без зала.
* Формы ничего не отправляют, после отправки показывают `settings.formDone`.
