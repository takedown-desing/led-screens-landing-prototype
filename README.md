# Лендинг LED-экранов, Москва и МО: прототип

Прототип одностраничного лендинга по приёму заявок на поставку и монтаж светодиодных экранов для компании «Хайнань Хэнпэн Международная Торговля». Этап 1 из 3 по брифу: прототип, затем утверждение, затем дизайн и разработка с управляемым контентом.

**Смотреть прототип:** https://takedown-desing.github.io/led-screens-landing-prototype/

**Сразу лендинг:** https://takedown-desing.github.io/led-screens-landing-prototype/landing.html

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | Обзор: ссылки, легенда пометок, бриф, структура 16 блоков с источником каждого, модель управляемого контента, медиа из брифа, спрос по Wordstat, что нужно от клиента |
| `landing.html` | Лендинг: шапка, первый экран с формой, полоса доверия, типы экранов, объекты на видео с фильтром, что входит, этапы, калькулятор, таблица подбора, о компании, отзывы, призыв, вопросы, контакты с формой, подвал, липкая панель, модальное окно |
| `CONTENT-MODEL.md` | Модель управляемого контента: сущности, поля, где выводятся, формы и журнал заявок |
| `assets/styles.css`, `assets/app.js` | Стили и интерактив: пометки, подсветка управляемых полей, меню, модальное окно, формы, фильтр кейсов, видео, калькулятор |
| `assets/img/` | Три фото из брифа, сжаты до 1600 px |
| `assets/video/` | Шесть видео из брифа, пережаты в H.264 без звука (1–6 МБ), плюс постеры |

## Пометки на блоках

Каждый блок лендинга подписан ярлыком в левом верхнем углу:

* синий «Из брифа»: блок или данные из брифа и материалов клиента;
* зелёный «Рекомендация»: блок добавлен по спросу и стандарту лендинга услуг;
* оранжевый «Заполняет клиент»: формат есть, данные условные;
* сине-зелёный: бриф плюс рекомендация.

Кнопка «Скрыть пометки» убирает ярлыки. Кнопка «Управляемые поля» обводит всё, что редактируется в админке. Значения с оранжевой заливкой условные: сроки, гарантия, число объектов, площади, ставки за м², реквизиты. Мобильная версия: сузьте окно до 820 px или откройте с телефона.

## На чём основан

1. Бриф: цель (заявки на экраны), компания, контакты (Иван Меньшов, +7 906 767 2566, imenshov@addu.ru), требование управляемого контента.
2. Материалы клиента: 3 фото (прозрачная панель спереди и сзади, гибкий модуль) и 6 видео объектов (медиафасад у трассы, прозрачная стена в шоуруме, пешеходный мост днём и ночью, интерьерная стена «волна», производство).
3. Спрос: Яндекс Wordstat, Москва и область, 28.09.2026. «светодиодный экран» 4 667, «led экран» 4 228, «медиафасад» 1 482 показов в месяц. Полная таблица в `index.html#demand`.

## Что нужно от клиента для следующего этапа

Реальные сроки, гарантия, ставки за м², реквизиты, адрес, режим работы, мессенджеры; по каждому видео город, площадь, шаг пикселя; отзывы; решения по набору блоков. Два ролика с трассы содержат китайские надписи на экране, для боевого сайта лучше заменить.
