# Лендинг LED-экранов, Москва и МО: прототип и админка

Прототип одностраничного лендинга по приёму заявок на поставку и монтаж светодиодных экранов для компании «Хайнань Хэнпэн Международная Торговля». Этап 1 из 3 по брифу: прототип, затем утверждение, затем дизайн и разработка. Контент управляемый: весь текст, цифры, фото и видео правятся в админке.

**Обзор прототипа:** https://takedown-desing.github.io/led-screens-landing-prototype/

**Лендинг:** https://takedown-desing.github.io/led-screens-landing-prototype/landing.html

**Админка:** https://takedown-desing.github.io/led-screens-landing-prototype/admin/

**Варианты дизайна:** https://takedown-desing.github.io/led-screens-landing-prototype/design/

## Варианты дизайна (этап 2)

Сделаны по видео-замечаниям клиента от 05.10.2026, сводка в `design/CLIENT-FEEDBACK.md`. Все варианты читают тот же `content/landing.json`, поэтому правки в админке видны в каждом из них. Пометки `[[...]]` в дизайне выводятся обычным текстом. Вместо статичных фото везде видео с автовоспроизведением: играет в кадре, на паузе вне кадра. Ролики типов экранов и блока «О компании» меняются в админке (поле «Видео»).

| Путь | Вариант | Референс |
|---|---|---|
| `design/v1/` | Светлый: светло-серый фон с WebGL-свечением, оранжевый акцент | промт студийного сайта (Axion Studio) |
| `design/v2/` | Контраст: чёрные и белые секции, оранжевые заглавные акценты, бегущая строка | сайт конкурента «Цвета Города» |
| `design/v3/` | Stitch: центрированная подача, синий #0066FF, свечение вокруг видео, синяя плитка гарантии | макет Google Stitch по `design/stitch/DESIGN.md` |
| `design/v4/` | Сцена: видео первого экрана при прокрутке монтируется на стену 3D-зала, синий #3054ff, светлые секции на линиях, тёмные блоки-экраны | макет дизайнера и отзыв Макса (led.addu.fun), подробности в `design/v4/README.md` |

Акцентный цвет каждого варианта задаётся одной CSS-переменной `--accent` в его `styles.css`.

Логотипы лежат в `design/logos/` (просмотр: `design/logos/index.html`): на каждый вариант основной `vN-logo.svg`, белый для тёмного фона `vN-logo-white.svg` и знак `vN-mark.svg` (иконка вкладки). Буквы в кривых, от шрифтов не зависят. В шапке и подвале вариантов стоит логотип-файл, поэтому поле «Название в шапке» в админке на варианты не влияет.

## Как менять контент

1. Откройте админку. Без входа она работает в демо-режиме: можно менять всё и сразу видеть результат в предпросмотре справа, но на сайт правки не попадают.
2. Чтобы публиковать, нажмите «Подключить публикацию» и вставьте токен GitHub. Как его получить, расписано в окне входа: fine-grained token только на этот репозиторий с правом Contents: Read and write.
3. Внесите правки и нажмите «Опубликовать» (или Ctrl+S). Текст и загруженные фото и видео уходят одним коммитом, сайт обновляется примерно через минуту. Админка сама покажет «Сайт обновлён».

Что можно менять:

* контакты, мессенджеры, название, title и description страницы;
* порядок блоков, показ и скрытие любого блока, пункты меню;
* тексты и списки каждого блока: добавлять, удалять, копировать, менять порядок карточек, объектов, этапов, вопросов, отзывов, строк таблиц;
* фото и видео: загрузка файла прямо из админки, превью для видео создаётся из кадра автоматически;
* ставки калькулятора за м², шаг пикселя, долю монтажа.

Текст в `[[двойных скобках]]` подсвечивается на сайте оранжевым как условный. Когда подставлены реальные данные, скобки убираются.

**История.** Кнопка «История» показывает все публикации. Любую прошлую версию можно открыть и опубликовать заново.

**Защита от затирания.** Если кто-то опубликовал правки, пока вы редактировали, админка остановит публикацию и предложит загрузить свежую версию.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | Обзор: ссылки, легенда пометок, бриф, структура блоков, модель контента, медиа, спрос, что нужно от клиента |
| `landing.html` | Оболочка лендинга, контент подставляется из `content/landing.json` |
| `content/landing.json` | Весь контент лендинга. Его правит админка |
| `assets/render.js` | Сборка страницы из JSON, режим предпросмотра для админки |
| `assets/app.js` | Интерактив: меню, модальное окно, фильтр объектов, видео, калькулятор, формы |
| `assets/styles.css` | Стили лендинга |
| `admin/` | Админка: `index.html` интерфейс, `schema.js` описание разделов и полей, `admin.js` редактор, `github.js` публикация через GitHub API |
| `assets/uploads/` | Файлы, загруженные через админку (появляется после первой загрузки) |
| `CONTENT-MODEL.md` | Структура контента: разделы, поля, где выводятся |
| `assets/img/`, `assets/video/` | Фото и видео из брифа |

## Как устроено

Хостинг статический (GitHub Pages), сервера нет. Админка работает в браузере: читает и пишет `content/landing.json` через GitHub API от имени владельца токена. Предпросмотр в админке это тот же `landing.html`, данные в него передаются напрямую, поэтому правки видны без публикации.

Формы в прототипе заявки не отправляют. Отправка на imenshov@addu.ru и в мессенджер, а также вход в админку по паролю без GitHub-аккаунта делаются на этапе разработки, для этого нужен небольшой сервер (например, Cloudflare Worker).
