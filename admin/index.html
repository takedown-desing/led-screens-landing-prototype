Подключить публикацию

Правки публикуются в репозиторий на GitHub, сайт обновляется сам примерно за минуту. Для входа нужен токен GitHub с правом записи в этот репозиторий.

Как получить токен (2 минуты)
  1. Войдите на GitHub под аккаунтом с доступом к репозиторию.
  2. Откройте github.com/settings/personal-access-tokens/new.
  3. Token name: «Админка лендинга». Expiration: срок действия, например 90 дней.
  4. Repository access: Only select repositories, выберите led-screens-landing-prototype.
  5. Permissions → Repository permissions → Contents: Read and write.
  6. Нажмите Generate token, скопируйте токен и вставьте ниже.

Токен хранится только в вашем браузере и отправляется только на api.github.com.
